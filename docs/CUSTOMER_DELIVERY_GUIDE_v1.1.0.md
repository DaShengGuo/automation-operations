# 宝可梦自动化购买脚本 — 客户部署与手机配置指南

适用版本: **v1.1.0**(安装包 `宝可梦自动化购买脚本_Setup_1.1.0.exe`)
本文档随安装包一起交付, 建议客户 IT/运营人员按顺序执行。

---

## 一、交付物清单

| 文件 | 说明 |
|------|------|
| 宝可梦自动化购买脚本_Setup_1.1.0.exe | 唯一需要安装的文件, 自带全部运行组件 |
| 本指南 | 电脑 + 手机 + 软件配置步骤 |

电脑端**不需要**安装 Python、ADB 或任何开发环境 — 安装包已全部自带。

---

## 二、电脑端安装(约 2 分钟)

1. 双击 `宝可梦自动化购买脚本_Setup_1.1.0.exe` → 下一步 → 安装
2. 桌面出现快捷方式「宝可梦自动化购买脚本」
3. 双击启动, 标题栏显示「**欢迎使用宝可梦自动化购买脚本**」+ 版本号 v1.1.0
4. 软件启动后处于「**已停止**」状态 — 不会自动操作手机, 可放心配置

> 首次运行如 Windows 弹出提示安装系统组件(VC++ 运行库), 属正常, 点击安装等待完成即可。
> 如遇杀毒软件拦截提示, 允许运行(软件为本地程序, 不联网上报数据)。

---

## 三、手机端配置(每台手机都要做, 约 5 分钟/台)

### 3.1 开启开发者选项

1. 打开手机「设置」→「关于手机」
2. 找到「版本号」, **连续快速点击 7 次**
3. 输入锁屏密码确认, 提示「您已处于开发者模式」

### 3.2 开启 USB 调试

设置 →「开发者选项」→ 打开「**USB 调试**」。

各品牌补充项:

| 品牌 | 开发者选项位置 | 额外需要打开的开关 |
|------|---------------|-------------------|
| 小米 / Redmi | 设置 → 更多设置 → 开发者选项 | **「USB 调试(安全设置)」+「USB 安装」**(漏开会导致无法操作) |
| 华为 / 荣耀 | 设置 → 系统和更新 → 开发人员选项 | 「仅充电模式下允许 ADB 调试」;USB 配置选 MTP |
| OPPO / Realme | 设置 → 其他设置 → 开发者选项 | — |
| vivo / iQOO | 设置 → 更多设置 → 开发者选项 | 「USB 模拟点击」 |
| 三星 | 设置 → 开发者选项 | — |
| Pixel / 原生 | 设置 → 系统 → 开发者选项 | — |

### 3.3 USB 连接与授权

1. 用**可传数据**的数据线连接电脑(建议原装线)
2. 手机下拉通知栏 → 点 USB 连接通知 → 选「**传输文件 / MTP**」(不要选「仅充电」)
3. 首次连接手机会弹出「**允许 USB 调试吗?**」→ **勾选「始终允许使用这台计算机」**→ 点「允许」
4. 没弹窗: 拔掉 USB 重新插入, 保持手机亮屏再看

### 3.4 网络与 VPN —— ⚠️ 最重要, 漏掉必卡登录

PTC 登录**必须**通过手机系统级 VPN 隧道, 否则登录网页无法打开、流程卡死。

- 手机安装 Clash 等代理软件后, **必须开启「TUN / 虚拟网卡(VPN)模式」** —
  **普通代理模式不算数**(实测: 普通代理模式下软件检测不到 VPN, 登录会卡)。
- 开启后几秒生效。软件启动时会**自动检测**每台手机: 未检测到会弹窗提示,
  此时到手机开好 TUN 模式, 回电脑点「已开启VPN」即可。
- 建议在手机上设置代理软件**开机自启 + 自动连接**, 避免运行中途断网。

### 3.5 其他准备

- 每台手机已安装 **Pokémon GO** 游戏;
- 运行期间手机保持亮屏、勿手动锁屏、勿拔线;
- 若使用「QQ 群取号」方式, 每台手机需**已登录 QQ 并加入接收账号的群**。

---

## 四、软件配置与开始运行

1. **账号来源**选择「QQ群聊」, 输入接收账号的 QQ 群名称。
   群内账号格式: **上一条消息 = 账号, 下一条 = 密码**(软件自动读取、自动去重)。
2. 点击「**确认并运行**」→ 软件自动执行: 保存配置 → 环境检测 → 扫描手机 → 开始生产。
3. 运行中看板实时显示每台手机状态; 结束后可导出 Excel 结果(账号已脱敏)。
4. **支付环节须知**: 默认流程到 Google Play 购买页时**暂停, 由人工完成支付**,
   支付完成后软件自动检测结果并继续下一个账号(安全设计, 防止误付款)。
5. 账号密码只保存在本机数据库, 日志与导出结果全部脱敏, 不联网上报。

## 五、日常操作

- **开始运行**: 从当前真实页面继续(不重新启动游戏/登录)
- **停止全部**: 所有设备在安全检查点退出(手机停在当前页面)
- **单设备停止**: 每台设备卡片上的「停止」按钮
- **重新识别**: 每台设备卡片上的「重新识别」按钮 — 识别手机真实页面并就地提示建议步骤
- **重新检测设备**: 手动重新扫描手机
- **自动识别当前步骤**: 识别手机真实页面 + 给出建议下一步
- **从选择步骤重新开始**: 选择步骤后校验手机页面, 匹配才继续, 不匹配会提示
- **历史记录**: 查看今天/全部执行记录, 可导出 Excel
- **打开日志目录**: 查看完整日志文件

## 六、设备环境重置(故障恢复)

每台设备卡片上有「**重置设备环境**」按钮, 用于以下场景的**人工**故障恢复:

- 测试环境恢复 / 手机本地状态异常 / 游戏缓存异常 / 登录页面状态混乱
- 设备自动化异常 / 自动化调试

**操作流程:**

1. 点击「重置设备环境」→ 弹出确认框(显示设备型号、当前账号脱敏、当前步骤)
2. 确认后软件自动执行: 停止该设备当前任务 → 清除 Pokémon GO 应用数据 →
   重新检测连接 → 重新初始化 → 识别手机真实页面 → 恢复就绪
3. 重置完成后, 下次运行从手机**真实页面**继续(清数据后出现的权限确认页/
   欢迎页等由软件自动处理)

**必须知道的边界:**

| 项目 | 说明 |
|------|------|
| 影响范围 | **只影响点击的那一台手机**, 其他手机继续运行不受影响 |
| 浏览器数据 | **默认不清除**(保护浏览器中已保存的登录状态); 高级选项「同时重置外部网页登录环境」默认关闭, 如需勾选请知悉会清除浏览器网站数据 |
| 当前账号 | 重置时正在执行的账号会退回队列等待重试(记录原因「设备重置」), **不会误记为成功** |
| 历史数据 | 运行日志、历史记录、数据库、错误记录**全部保留**, 只清手机端游戏数据 |
| 触发方式 | 只有人工点击才会重置, 软件不会自动清理游戏数据 |
| 失败提示 | 重置失败会在该设备卡片显示具体失败步骤和原因, 可重新点击重试 |

> 说明: 本功能仅用于恢复自动化运行环境, 不是用于绕过平台账号/设备/
> 风控限制的机制; 软件检测到账号限制或平台风控时, 会截图取证、记录并
> 停止该设备的自动化, 不会自动清数据或继续尝试。

## 七、首次联调建议(重要)

1. 先 **1 台手机 + 1 个账号**跑通完整流程(登录 → 商店 → 购买 → 登出), 确认无问题;
2. 再逐步增加到 3 台手机;
3. 遇到问题: 软件内点「打开日志目录」, 把日志发给开发方, 便于定位
   (设备重置的操作记录在日志目录 `device_reset.log` 中)。

> 如实告知: 本版本 258 项自动化测试全部通过, **设备环境重置功能已在
> 单台真机(Redmi M2012K11AC, Android 13)完整验证通过**。多台设备同时
> 重置互不影响、干净电脑首装、三机并发生产仍待三机环境验证;
> 首次使用请先按第七节节奏联调。

## 八、常见问题自查

| 现象 | 处理 |
|------|------|
| 软件检测不到手机 | 重插数据线; 手机重新开关「USB 调试」; 检查 3.2 品牌补充开关; 电脑首次连接该品牌手机需等待驱动自动安装 |
| 弹「未检测到 VPN」 | 按 3.4 开启 TUN/虚拟网卡模式, 几秒后点「已开启VPN」 |
| 登录环节卡住 | 确认 VPN 在线(3.4)、账号密码有效; 若账号已失效, 软件会自动跳过该账号继续下一个 |
| 登录页面混乱/游戏缓存异常 | 点该设备卡片「重置设备环境」(见第六节), 完成后重新开始运行 |
| 某台手机状态异常 | 软件内「重新检测设备」; 手机保持亮屏 |
| 手机弹「是否允许 USB 调试」 | 勾选「始终允许」→ 允许(中断运行后需要重新确认) |
