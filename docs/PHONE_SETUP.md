# 手机设置教程

用 USB 连接电脑前，手机需要先完成以下设置。

---

## 第一步：开启开发者选项

### 通用安卓方法

1. 打开手机「设置」
2. 进入「关于手机」或「关于本机」
3. 找到「版本号」或「版本信息」
4. **连续快速点击 7 次**「版本号」
5. 输入锁屏密码确认
6. 提示「您已处于开发者模式」

---

## 第二步：开启 USB 调试

1. 打开「设置」
2. 进入「开发者选项」（位置见下方各品牌说明）
3. 找到并**打开**「USB 调试」
4. 如有「禁止权限监控」，也打开

---

## 第三步：USB 连接模式

1. 用数据线连接电脑
2. 手机顶部下拉通知栏
3. 点击 USB 连接通知
4. 选择「**传输文件**」或「**MTP**」模式
5. **不要**选「仅充电」

---

## 第四步：授权 USB 调试

1. 第一次连接电脑时，手机屏幕会弹出对话框
2. 标题类似：「允许 USB 调试吗？」
3. **勾选**「始终允许使用这台计算机」
4. 点击「**允许**」

> ⚠️ 如果没弹窗：拔掉 USB → 重新插入 → 解锁手机屏幕查看

---

## 各品牌特殊说明

### 小米 / Redmi

- 开发者选项位置：设置 → 更多设置 → 开发者选项
- 除了「USB 调试」，还需打开：
  - **「USB 调试（安全设置）」**
  - **「USB 安装」**

### 华为 / HarmonyOS

- 开发者选项位置：设置 → 系统和更新 → 开发人员选项
- 如果有「仅充电模式下允许 ADB 调试」，打开
- USB 配置选择「MTP（媒体传输协议）」

### 荣耀

- 开发者选项位置：设置 → 系统和更新 → 开发人员选项
- 同华为设置

### OPPO / Realme

- 开发者选项位置：设置 → 其他设置 → 开发者选项
- （需先在「关于本机」连点版本号激活）

### vivo / iQOO

- 开发者选项位置：设置 → 更多设置 → 开发者选项
- USB 调试开启后可能还需开启「USB 模拟点击」

### 三星

- 开发者选项位置：设置 → 开发者选项
- USB 调试开启后，连接电脑时注意选择「传输文件」

### Pixel / 原生 Android

- 开发者选项位置：设置 → 系统 → 开发者选项

---

## 验证是否成功

电脑上双击 `check-device.bat`，如果显示「设备就绪」即表示成功。
